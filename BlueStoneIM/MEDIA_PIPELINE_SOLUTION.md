# BlueStoneIM 媒体收发(图片/视频/文件)完整解决方案

> 范围:聊天界面 + 底部「文件」界面的图片/视频/文件的 **发送 → 缩略图/预览 → 下载 → 查看 → 保存 → 分享** 全链路。
> 本文档只描述方案(前端 UX + 客户端架构 + 后端 + CDN),不含代码改动。
> 现状基线据代码扫描:已具备 presign 直传+上传进度、CDN 签名下载、按 `cacheKey` 的本地磁盘缓存+大小校验+下载去重/进度/失败态、`thumbnailURL` 字段。下文标注「已有 / 待补 / 待确认」。

---

## 0. 设计原则(业界通行)
1. **大文件永不经过业务服务器**:客户端 ↔ 对象存储直传/直下(presign),业务服务器只发签名与存元数据。(已有)
2. **内容寻址 + 不可变 URL**:对象 key 用内容哈希,URL 不变 → CDN 可长期强缓存、天然去重/秒传。(部分已有:`cacheKey`)
3. **渐进式呈现**:占位(模糊/主色)→ 缩略图 → 预览图 → 原图/原视频,逐级加载,布局不跳动。
4. **一次下载,多处复用**:本地缓存命中即用,绝不重复下载;分缩略图层和原件层。(已有原件层)
5. **乐观发送**:本地先上屏(缩略图 + 上传进度),后台直传,失败可重试,成功回填远端 key。
6. **元数据先行**:消息里带 `width/height/duration/size/mime/blurhash/缩略图key`,收到即可定尺寸+占位,无需先下载。
7. **私有桶 + 短时签名 + CDN 鉴权**:原件私有,签名 URL 短时效;缩略图可走带 token 的 CDN 边缘缓存。

## 1. 前端用户体验(目标态)

### 1.1 聊天界面 — 图片
- 气泡内**直接显示缩略图**,按真实宽高比占位(收到消息即用 `width/height` 定框,避免跳动);加载顺序:`blurhash/主色占位` → `缩略图(CDN 边缘缓存)` → 点击 → 全屏大图(preview 尺寸)→ 双指放大看原图。
- 全屏查看器:左右滑切换同会话图片、捏合缩放、下拉关闭、底部「保存 / 分享 / 原图」。
- 失败态:占位上显示「重新加载」。

### 1.2 聊天界面 — 视频
- 气泡内显示**视频封面(poster)** + 时长角标 + 播放按钮 + 体积(大文件时)。
- 点击:小视频直接内联/全屏播放(边下边播,渐进式 MP4 或 HLS);大视频先显示「下载 XX MB」按钮,带进度环、可取消;下完转「播放」。
- 静音自动循环预览(可选,仿主流 IM 短视频预览)。

### 1.3 聊天界面 — 文件(文档/压缩包等)
- 气泡显示:文件类型图标 + 文件名 + **大小** + 状态。
- 未下载:显示「下载」按钮(带体积);点击 → **线性/环形进度 + 可取消**;完成 → 「打开」。
- 已下载:直接「打开」(用系统 QuickLook 预览),不再下载。
- 长按:保存到「文件」App / 分享 / 转发 / 收藏。

### 1.4 底部「文件」界面
- 聚合当前用户/企业可见的文件,列表项含:图标/缩略图、文件名、大小、来源会话、时间、下载状态。
- 支持:搜索、按类型筛选、下载/打开、保存、分享、批量管理。
- 复用与聊天**同一套缓存与下载管理器**,状态一致(聊天里下过的,这里直接「打开」)。

### 1.5 发送体验(图片/视频/文件通用)
- 选择后**立即上屏**占位气泡 + 上传进度环(乐观发送);本地先生成缩略图/封面即时显示。
- 后台:压缩/转码 → presign → 直传(带进度)→ markUploaded → 回填远端 key → 气泡转为正常。(直传+进度已有)
- 失败:气泡显示「重试」,不丢用户内容;弱网自动重试 + 断点续传。
- 多选:并发上传(带并发上限),逐条独立进度。

### 1.6 保存与分享
- 图片/视频:保存到系统相册(请求权限);文件:保存到「文件」App。
- 分享:系统 Share Sheet(`UIActivityViewController`),分享本地缓存文件,无需重新下载。

## 2. 客户端架构(iOS)

### 2.1 统一媒体管线 `MediaPipeline`
把「上传 / 下载 / 缓存 / 缩略图 / 生命周期」收口到一个组件(目前这些逻辑散落在 AppState 里),对外暴露:
- `thumbnail(for:) -> Image`(异步、走缓存)
- `download(message, kind) -> progress stream + localURL`
- `upload(asset) -> progress stream + remoteFile`
- `cachedURL(for:)`、`cancel(id:)`、`retry(id:)`

### 2.2 三级 URL / 三级资源
| 级别 | 用途 | 大小 | 缓存策略 |
|---|---|---|---|
| thumbnail | 列表/气泡缩略图 | ~小(几十 KB) | CDN 强缓存 + 客户端内存(NSCache)+ 磁盘(长期) |
| preview | 全屏看图、内联播放 | 中(限边长/码率) | 磁盘(中期 LRU) |
| original | 下载/保存/转发 | 原始 | 磁盘(长期,大小上限 LRU)|

消息 payload 同时带三者的 key/URL + 元数据(见 §3.3)。

### 2.3 缓存(关键:不重复下载)
- **内容寻址**:磁盘缓存按 `cacheKey`(服务端内容哈希)命名;相同文件全局只存一份。(已有 `cacheKey` + 大小校验)
- **两层**:① 内存 `NSCache`(已解码 UIImage,缩略图,受内存压力自动回收);② 磁盘(Caches 目录,缩略图/preview/original 分目录)。(磁盘已有)
- **命中即用**:打开前先查磁盘命中,有则直接用(已有 `cachedLocalAttachmentURL`)。
- **LRU 清理(待补)**:设总容量上限(如 1–2 GB)+ 单文件上限;超限按最近最少使用淘汰;按钮「清理缓存」与体积显示。系统在低磁盘时会清 Caches,需保证可重新拉取(已是内容寻址,安全)。
- **缩略图永久化**:缩略图内容寻址 + 体积小 → 可长期保留,保证列表秒开。

### 2.4 下载管理(待打磨)
- 并发上限队列(如同时 3–4 个),优先级:用户主动点击 > 预取。
- **断点续传**:HTTP Range,`URLSessionDownloadTask` resumeData;弱网/切后台续传。
- 进度、取消、失败重试(已有进度/失败态,补断点与队列)。
- 预取(可选):进入会话/滚动到附近时,后台预取缩略图与小图。

### 2.5 上传(已有直传,补压缩/转码)
- **图片**:发送前压缩(HEIC/JPEG,限最大边长与质量),保留原图可选;本地生成缩略图。
- **视频**:转码为兼容封装(H.264/AAC mp4 或 HEVC,`AVAssetExportSession`),限码率/分辨率;抽取封面帧作 poster;大视频给「原画质/标清」选项。
- 生成本地缩略图/封面 → 乐观上屏 → presign 直传(带进度)→ markUploaded。(直传/进度已有)
- 失败重试 + 断点续传上传(分片,大文件)。

### 2.6 查看与播放
- 文件:`QLPreviewController`(系统 QuickLook),覆盖 PDF/Office/图片等。
- 图片:自研全屏查看器(缩放/翻页/保存/分享)。
- 视频:`AVPlayer` 渐进式播放;HLS 时直接流式(边下边播,不必整文件下完)。

## 3. 后端处理逻辑

### 3.1 存储与直传(已有)
- 对象存储(阿里云 OSS / S3 / MinIO 兼容),**按租户隔离路径**;私有桶。
- 上传:`presign-upload` 返回 PUT 直传 URL,客户端直传对象存储;`markFileUploaded` 落元数据。
- 下载:`presign-download` 返回签名 URL;已支持 **CDN 下载域名**(`PublicCDNDownloadFileURLSigner`,按租户 `cdn_base_url`),上传保持私有、下载走 CDN。

### 3.2 缩略图 / 预览 / 转码(核心待补)
两条路线,二选一或并用:
- **A. 即时图片处理(推荐起步,零离线管线)**:用 OSS/CDN 的图片处理能力(如阿里云 OSS `?x-oss-process=image/resize,w_480` 或 CDN 图片处理),由 URL 参数即时生成多尺寸缩略图/preview,边缘缓存。图片类几乎零额外后端工作。
- **B. 上传后异步处理(视频必需)**:`markUploaded` 触发处理队列(已有 messageexport/worker 模式可参考):
  - 图片:生成 thumbnail/preview 多尺寸 + `blurhash`/主色 + 读 `width/height`。
  - 视频:抽封面帧(poster)+ 转码(标清+原画质)+ 可选 HLS 切片;读 `duration/width/height`。
  - 处理结果写回文件元数据;完成前消息先用「本地缩略图 + 处理中」占位。

### 3.3 文件元数据(驱动前端布局/占位,待补字段)
文件记录与消息 payload 建议包含:
`file_id, object_key, cache_key(内容哈希), mime, size, width, height, duration, blurhash/主色, thumbnail_key, preview_key, original_key, status(processing/ready)`。
→ 客户端收到消息即可定框 + 占位 + 决定「直接看缩略图」还是「显示下载按钮」。

### 3.4 签名与安全
- 私有桶;下载签名 URL **短时效**(如 5–15 min);缩略图可用更长时效或公有读 CDN(内容寻址 + token)。
- CDN **鉴权**:URL 签名 / 防盗链 Referer / Token,避免签名泄漏后长期可下。
- 按租户隔离路径与权限校验(成员/会话可见性)。
- 可选:上传后病毒/敏感内容扫描(异步,处理队列里做)。

### 3.5 去重 / 秒传(待补)
- 客户端上传前算文件内容哈希(sha256)→ 调 `precheck`,若服务端已有相同哈希对象 → **直接引用,秒传**,跳过上传。
- 内容寻址使 CDN/客户端缓存天然全局去重。

### 3.6 大文件分片上传(待补)
- 超过阈值(如 50–100 MB)走分片 + 断点续传(OSS Multipart),弱网友好。

## 4. CDN 策略
- **架构**:私有 OSS 源站 + CDN 加速域名,CDN 回源 OSS;下载走 CDN(已有),上传直连 OSS(私有)。
- **缩略图/preview**:内容寻址 key 不变 → CDN 长 TTL 强缓存(`Cache-Control: public, max-age=很长`),边缘命中,列表秒开。
- **原件**:私有 + 短时签名;CDN 上做 token 鉴权,过期失效。
- **图片处理**:OSS/CDN 即时处理参数生成多尺寸,处理结果同样边缘缓存。
- **就近 + 回源收敛**:多租户共享 CDN,按租户路径前缀;热点文件边缘扛量,源站压力低。

## 5. 端到端时序

**发送图片**
1. 选图 → 本地压缩 + 生成缩略图 → 乐观气泡上屏(缩略图 + 进度环)。
2. (可选)算哈希 → precheck 秒传;未命中 → presign → 直传 OSS(进度)→ markUploaded。
3. 服务端即时/异步生成多尺寸 + 元数据 → 消息回填 key/尺寸 → 气泡转正常。

**接收并看缩略图**
1. 收到消息(带 `width/height/blurhash/thumbnail_key`)→ 立即按比例占位 + 模糊图。
2. 异步取 thumbnail(CDN 边缘命中)→ 渲染;不下载原件。

**点击下载原件**
1. 查本地缓存(cacheKey)→ 命中直接打开/播放。
2. 未命中 → 取签名 URL → 下载(Range 断点 + 进度 + 可取消)→ 落磁盘(按 cacheKey)→ 打开。

**再次查看**
- 直接命中本地缓存,零网络。

**保存/分享**
- 用本地缓存文件:存相册 / 存「文件」/ 系统 Share Sheet。

## 6. 现状差距与落地优先级

**已有(据扫描)**:presign 直传 + 上传进度;CDN 签名下载;按 cacheKey 的磁盘缓存 + 大小校验;下载去重/进度/失败态;thumbnailURL 字段。

**主要差距(建议执行方核对后补)**,按「体验收益 / 成本」排序:
1. **服务端缩略图/preview(图片)**——用 OSS/CDN 即时图片处理最省力,直接让聊天/文件列表显示真缩略图。**收益最高、成本低**。
2. **元数据(width/height/size/duration/blurhash)入消息**——消除布局跳动、即时占位、即时判断「看缩略图 vs 下载按钮」。**收益高、成本中**。
3. **缓存 LRU 上限 + 清理入口**——避免缓存无限增长;保证「下过不再下」长期成立。**成本低**。
4. **视频封面 + 渐进/HLS 播放**——视频体验从「先下完才看」到「点开即播」。**收益高、成本中**(需转码队列)。
5. **下载断点续传 + 并发队列 + 预取**——弱网与列表滚动体验。**成本中**。
6. **保存到相册 / Share Sheet / QuickLook 打磨**——保存分享顺手。**成本低**。
7. **内容哈希秒传 + 大文件分片**——省流量、提速、弱网稳。**成本中**。
8. **CDN 鉴权(token/防盗链)+ 签名时效收敛**——安全。**成本低中**。

**建议起步组合(投入小、体验跳变最大)**:1 + 2 + 3 + 6 —— 即「服务端出缩略图 + 元数据驱动占位 + 缓存上限 + 保存分享打磨」,聊天与文件页立刻变成「秒见缩略图、文件有大小和下载进度、下过不再下、可保存分享」。视频流播放(4)与秒传/分片(7)作为第二批。

> 说明:以上「待补/待确认」项需执行方对照后端 messageexport/worker、tenant/file_signer、storage_resolver 与 iOS AppState 媒体相关函数核实后再定边界;本方案为目标架构与优先级,不含具体代码改动。

## 7. 交互细则:点击行为 / 按钮 / 弹窗清单

> 本节定义每种媒体「点一下发生什么、有哪些按钮、各状态怎么变、需要哪些新页面/弹窗」。

### 7.1 媒体气泡通用状态机(图片/视频/文件共用)
每个媒体气泡在以下状态间流转,按钮随状态变化:

| 状态 | 触发 | 气泡上的控件 | 单击行为 |
|---|---|---|---|
| `processing` 服务端处理中 | 刚发出/对端刚发,缩略图未就绪 | 模糊占位 + 小转圈「处理中」 | 无(或提示稍候) |
| `ready_remote` 已就绪未下载 | 收到消息,缩略图已显示 | 图片:缩略图可点;视频:封面+播放钮+时长;文件:图标+名+**大小**+「下载」 | 见 7.2/7.3/7.4 |
| `downloading` 下载中 | 点了下载/打开 | **进度环/进度条 + 百分比 + 取消(×)** | 再点=取消 |
| `downloaded` 已下载 | 下载完成 | 图片/视频:正常缩略图/封面;文件:图标+名+大小+「打开」 | 见 7.2/7.3/7.4(走本地,零网络) |
| `failed` 失败 | 网络/签名失败 | 占位上「重试」+ 失败图标 | 点=重试 |
| `expired` 签名过期 | 远端 URL 过期 | 对用户透明 | 自动刷新签名后继续 |

要点:**缩略图与「原件是否已下载」解耦**——图片/视频的缩略图/封面在 `ready_remote` 就显示(走 thumbnail,不占原件下载);"下载"只针对原图/原视频/原文件。

### 7.2 图片 — 点击行为
- **单击缩略图** → 打开**全屏图片查看器**(自研页面,非系统弹窗)。
  - 进入即用已缓存缩略图做底图,后台拉 preview(中清)→ 替换;右上「原图」按钮按需拉 original。
  - 手势:捏合/双击放大、拖动平移、**左右滑切换本会话其它图片**、**下拉关闭**。
  - 顶部/底部浮层按钮:`关闭(×)`、`保存到相册`、`分享`、`原图(显示原图体积,点了才下原图)`、`…更多`(转发 / 收藏 / 删除[仅自己发的] / 在文件中查看)。
- **长按缩略图(气泡上,不进查看器)** → 上下文菜单(见 7.5)。
- 状态:`downloading` 时缩略图上盖进度;`failed` 显示重试。

### 7.3 视频 — 点击行为(按体积/可否流播分流)
- **封面常显**:`ready_remote` 即显示 poster + 时长角标 + 播放钮;大视频额外显示体积。
- **单击播放钮**:
  - 小视频 / 支持流播(HLS 或可 Range 渐进) → 直接进**系统播放器**(`AVPlayerViewController`,全屏),**边下边播**,原生控件(播放/暂停、进度条、音量、AirPlay、画中画、全屏)。
  - 大视频且未下载且不可流播 → 气泡转 `downloading`(进度环 + 取消);下完自动/再点进播放器。
- **可选**:列表中静音自动循环预览(仿主流短视频),点击才出声进全屏。
- **长按** → 上下文菜单(保存到相册 / 分享 / 转发 / 收藏 / 删除)。
- 播放器内按钮:系统控件 + 自定义 `保存` / `分享`(右上)。

### 7.4 文件 — 按类型点击行为
单击「打开」前若未缓存,先 `downloading`(进度+取消),下完再按类型处理:

| 类型 | 例 | 打开方式 | 说明 |
|---|---|---|---|
| 可预览文档 | PDF / Word / Excel / PPT / txt / 图片文件 | **系统 QuickLook**(`QLPreviewController`)全屏预览 | QL 自带分享按钮;覆盖绝大多数办公文档 |
| 音频 | mp3 / m4a / 语音文件 | 内联迷你播放器或 `AVPlayer` | 可气泡内播放 |
| 压缩包 | zip / rar / 7z | **不预览** → 弹「用其他应用打开 / 存到文件 / 分享」 | iOS 不原生解压 |
| 未知/不支持 | 各种 | 同上:「用其他应用打开」(`open-in`) / 存到文件 / 分享 | 兜底 |
| 超大文件 | > 阈值 | 先确认再下(见 7.7 蜂窝提示) | 防误触大流量 |

- **已下载**的文件:单击直接 QuickLook/播放器/open-in,**不再下载**。
- **长按** → 上下文菜单。

### 7.5 统一长按上下文菜单(`UIContextMenu` / 操作面板)
对图片/视频/文件气泡长按,弹出统一菜单(按权限/类型增减项):
`保存`(图片/视频→相册;文件→文件App)、`分享`(系统 Share Sheet)、`转发`、`收藏`、`引用/回复`、`多选`、`删除`(仅本人发送且在可撤回/可删策略内)、`复制`(图片)、`在「文件」中查看`。

### 7.6 需要新增的页面 / 弹窗清单(明确系统 vs 自研)
**自研(需要开发)**
1. **全屏图片查看器**(缩放/翻页/下拉关闭/浮层按钮)——核心新页面。
2. **媒体气泡的多状态视图**(processing/ready/downloading/downloaded/failed 的进度环、下载按钮、体积、封面)。
3. **长按上下文菜单**(可用 SwiftUI `contextMenu` 或自研操作面板)。
4. **多选模式**:进入后顶部「已选 N」、底部操作栏(转发/保存/删除/分享)。
5. **「用其他应用打开」入口**(不可预览类型)——基于系统 open-in,但需触发 UI。
6. **设置里「存储与缓存」**:占用体积 + 清理缓存按钮 + 确认弹窗。
7. **蜂窝大文件提示弹窗**(见 7.7)。

**系统提供(直接用,无需自研 UI)**
- 系统分享面板 `UIActivityViewController`(分享/存文件/拷贝等)。
- QuickLook 预览 `QLPreviewController`(文档)。
- 视频播放器 `AVPlayerViewController`。
- 保存相册权限请求(系统)+ 成功/失败用 toast 反馈。
- open-in(`UIDocumentInteractionController` / share sheet 的"拷贝到 App")。

### 7.7 边界与提示(需要的确认/错误弹窗)
- **蜂窝网络 + 大文件/原图/视频**:首次点下载弹确认「当前为蜂窝网络,下载 XX MB?[取消][下载][始终允许]」;Wi‑Fi 下不打扰。设置项「仅 Wi‑Fi 自动下载」。
- **保存相册**:首次请求权限;成功 toast「已保存到相册」,失败 toast 说明原因。
- **不支持预览**:toast/弹窗「无法预览此类型,可[用其他应用打开][存到文件]」。
- **下载失败 / 文件已过期 / 被撤回**:气泡置 `failed`/灰显,toast 说明;过期签名自动续签对用户透明。
- **发送失败**:气泡「重试」,长按可删除草稿气泡。
- **清理缓存**:确认弹窗「清理后再次查看需重新下载,确定?」。

### 7.8 「文件」Tab 的差异点
- 与聊天**共用同一缓存与下载管理器**:聊天里下过的,文件页直接「打开」,反之亦然。
- 列表项点击 = 7.4 的文件单击逻辑;缩略图列(图片/视频)显示小预览。
- 顶部:搜索、类型筛选(图片/视频/文档/其它)、排序;支持多选批量(下载/保存/分享/删除)。
- 每项右侧状态:未下载显示体积+下载图标;已下载显示「打开」;下载中显示进度。

### 7.9 一句话决策树(单击)
图片→全屏查看器;视频→(可流播?直接播:先下后播);文件→(已缓存?按类型预览/open-in:先下载带进度,完再按类型处理)。所有类型长按→统一菜单。
